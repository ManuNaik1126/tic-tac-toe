
# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Play the classic two-player game and try to get three marks in a row to win!

## 📌 About the Project

This project is a browser-based implementation of the classic Tic-Tac-Toe game. It provides a simple interface where two players take turns marking cells on a 3×3 grid.

## ✨ Features

- Interactive 3×3 game board
- Two-player gameplay
- Automatic winner detection
- Draw detection when all cells are filled
- Simple and user-friendly interface
- Option to restart the game (if implemented)

## 🛠️ Technologies Used

- HTML — Structure of the game
- CSS — Styling and layout
- JavaScript — Game logic and interactivity

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/ManuNaik1126/tic-tac-toe.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!
